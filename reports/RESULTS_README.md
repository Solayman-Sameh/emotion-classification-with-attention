# Experiment outputs

Mode: full. Full training: validation selection was frozen before the held-out test phase.

Confusion matrices and class support are reported separately. Review fear/disgust supports, negation/OOV/truncation slices, and errors.jsonl before interpreting overall scores. Mixed emotions and neutral are excluded from training; the app has no neutral/mixed class. Published mapping broadens surprise to include cognitive labels. Attention and directionality differ between baselines, so improvements cannot be attributed solely to attention. Calibration and causal importance are not established. Concurrent timings are not isolated benchmarks.

Code, dependencies, source revisions, hashes, preprocessing and exact record identities are persisted. Interrupted models restart; compatible completed models can be reused. No optimizer-state resume is claimed.
